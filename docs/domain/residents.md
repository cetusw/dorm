# Жители

## Назначение

`User` описывает жителя, который может:

- входить в resident web-приложение;
- состоять в команде;
- быть главой команды, группы или общежития;
- получать предупреждения и уведомления.

## Идентичность

Поля идентичности:

- `id`
- `login`
- `password_hash`
- `first_name`
- `middle_name`
- `last_name`
- `created_at`

Аутентификация — логин/пароль. Пароль хешируется SHA-256 без соли в `user.Service`.

Это текущее реализованное состояние; отдельного внешнего auth-provider нет.

## Организационная принадлежность

Текущая принадлежность хранится отдельно от идентичности:

- `dormitory_id`
- `team_id`
- `floor_number`
- `room_number`

Группа выводится косвенно через текущую команду: `user.team_id -> team.group_id`.

## Полномочия

Полномочия не хранятся отдельным enum.

Они выводятся из:

- `dormitory.leader_id`
- `group.leader_id`
- `team.leader_id`
- `user.team_id`

Смена этих связей немедленно меняет права пользователя.

## Soft delete

Удаление жителя — soft delete через `user.deleted_at`.

Следствия:

- пользователь исчезает из обычных выборок и логина;
- предупреждения, уведомления и история дежурств остаются в БД;
- push subscriptions и notifications каскадно очищаются только если запись пользователя была бы удалена физически, чего текущий код не делает.

## Изменение команды

Смена команды делается через `MoveUserToTeam`.

Влияние:

- resident task permissions сразу переключаются на новую команду;
- пользователь может потерять доступ к старому active duty, если больше не состоит в его команде;
- история прошлых дежурств не закрепляет его старую роль как snapshot.

## Login contract

Проверки `user.Service`:

- логин обязателен;
- допустимые символы: `[a-z0-9._-]`;
- пароль обязателен;
- для UI bootstrap первый пользователь создаётся отдельным shell script.

Имена жителей в CRUD:

- backend ожидает кириллицу в имени и фамилии;
- frontend использует собственные формы и валидацию поверх API.

## Где реализовано

- домен: `pkg/core/domain/user/user.go`
- auth и current user: `pkg/core/usecase/user/service.go`
- HTTP: `pkg/adapters/http/resident_auth.go`, `user.go`
- persistence: `pkg/infrastructure/mysql/repository/user.go`
