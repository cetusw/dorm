# Specifications

`docs/specifications` — место для требований, исторических заметок и legacy-контекста.

В отличие от:

- `docs/architecture`
- `docs/domain`
- `docs/api`
- `docs/operations`

эти документы не описывают текущее поведение как источник истины.

Сейчас каталог содержит:

- [legacy-context.md](./legacy-context.md) — заметки о старых ожиданиях, которые больше не совпадают с runtime.
